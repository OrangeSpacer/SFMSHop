# Git Workflow для проекта SFMShop

## Использованные команды Git

- git init - инициализация репозитория
- git add - добавление файлов в staging area
- git commit - для комментирования diff и создания слепка измнений
- git push - отправки измнений в удаленное хранилище
- git pull - для получения удаленных измений в ветке
- git rebase - для переноса текущих коммитов поверх новых в главной ветке

## Созданные ветки

- main - основная ветка проекта
- feature/add-discount-system - ветка для системы скидок
- feature/add-inventory-management - для для управления складом
- feature/add-shipping - ветка для настроки измнения цены/ко-ва това при отправке

## Разрешенные конфликты

- Конфликт в src/models/product.py при слиянии feature/add-discount-system
- Конфликт при rebase feature/add-shipping от develop
- Конфликт для get_total_price в product.py. Необходимо совместить скидку и округление

## Стратегия работы с ветками

- для каждой новой задачи создается новая ветка от develop
- у каждой новой ветки в начале добавляется feature/...
- коммит производится на русском языке
